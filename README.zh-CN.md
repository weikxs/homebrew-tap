# weikxs/homebrew-tap

[English](README.md) | **简体中文**

[weikxs](https://github.com/weikxs) 发布的各个工具的 [Homebrew](https://brew.sh) 软件包。

## 安装

```sh
brew install weikxs/tap/<工具名>
```

或者先 tap 一次，之后按名字安装：

```sh
brew tap weikxs/tap
brew install <工具名>
```

## 工具

| 工具 | 简介 | 平台 |
|---|---|---|
| [gitpersona](https://github.com/weikxs/gitpersona) | 跟着目录自动切换的 Git 身份 | macOS（第一个正式版本发布后可用） |

这里的软件包是 macOS 用的 Cask，由各工具的发布流程自动写入，请不要手动修改。
Linux 上请从各项目的 Release 页面下载，或用 `go install` 安装，具体见各项目的 README。

## 问题反馈

请在对应工具自己的仓库里提 issue。
